# English to German Translator

A web-based English-to-German translation application built with **Gradio** and **Hugging Face Transformers**. It leverages the pre-trained `t5-base` model to provide fast, accurate text translations through an interactive browser interface.

## Features
- **Interactive UI:** Clean web interface powered by Gradio `Blocks`.
- **Pre-trained NLP Model:** Uses Hugging Face's `translation_en_to_de` pipeline with `t5-base`.
- **Quick Examples:** Includes built-in sample phrases for one-click testing.

## Prerequisites
- Python 3.8 or higher
- `pip` package manager
